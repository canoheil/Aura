# آورا (Aura)

**دستیار هوش مصنوعی خودمیزبان برای تلگرام — دوزبانه، مستقل از فروشندهٔ مدل، و سخت‌گیر در گفتن حقیقت.**

[![tests](https://github.com/canoheil/Aura/actions/workflows/tests.yml/badge.svg)](https://github.com/canoheil/Aura/actions/workflows/tests.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![python](https://img.shields.io/badge/python-3.11%2B-blue.svg)](pyproject.toml)

[English](README.md) · [فارسی](README.fa.md)

آورا دستیار شخصی‌ای است که در تلگرام زندگی می‌کند: گفتگو را ادامه می‌دهد، چیزهایی
که مهم‌اند را به یاد می‌سپارد، عکس‌ها، استیکرها، فایل‌ها و ویس‌هایی که برایش
فرستاده می‌شود را می‌فهمد، وقتی سؤال دربارهٔ چیزی است که تازه تغییر کرده در وب
جستجو می‌کند، یادآور یک‌باره می‌سازد، و تصویر می‌کشد — تصویرهای برداری را
به‌صورت محلی، و عکس‌های واقع‌گرایانه را از سرویسی که می‌توانی خاموش بگذاری.

همهٔ این‌ها یک فرایند پایتون است روی یک فایل SQLite. نه داکر، نه Redis، نه
Postgres، نه وبهوک، و نه هیچ حساب ابری‌ای جز کلید API مدل.

---

## چرا آورا

**اول فارسی حرف می‌زند.** فارسی زبان پیش‌فرض رابط است، نه ترجمه‌ای که بعداً
چسبانده باشند: کاتالوگ هر دو زبان را دارد، تست‌ها روی رشتهٔ گم‌شده fail
می‌شوند، و رندر محلی SVG متن فارسی را درست شکل می‌دهد و برعکس نمی‌کند. انگلیسی
با یک `/language en` در دسترس است.

**به یک فروشندهٔ مدل گره نخورده.** همان موتور عامل روی SDK بومی Gemini یا هر
درگاه `POST /chat/completions` کار می‌کند — OpenAI، OpenRouter، Groq، DeepSeek،
Together، Fireworks، vLLM، LM Studio، Ollama. عوض‌کردن ارائه‌دهنده هیچ‌وقت حلقهٔ
ابزار، بودجه‌ها یا بررسی شواهد را شل نمی‌کند، و از داخل تلگرام و بدون ری‌استارت
انجام می‌شود.

**ترجیح می‌دهد بگوید «نمی‌توانم تأیید کنم» تا اینکه حدس بزند.** مدل نمی‌تواند
بفهمد دانش خودش کهنه شده. آورا این تصمیم را در کد می‌گیرد، نه در پرامپت:
سؤال‌های وابسته به زمان را تشخیص می‌دهد، برای آن‌ها جستجو را اجباری می‌کند، و
وقتی جستجو خالی برمی‌گردد، یک واقعیت از حافظه را به‌عنوان «امروز» ارائه نمی‌دهد.

**رسانه‌هایی را که مردم واقعاً می‌فرستند می‌فهمد.** عکس، سند تصویری، استیکر
(از جمله انیمیشنی و ویدیویی)، ویس، صدا، ویدیو، ویدیومسیج و فایل به مدل
می‌رسند، هرکدام با چارچوبی که لازم دارد.

**همهٔ تنظیمات از داخل تلگرام در دسترس‌اند.** `/admin` ارائه‌دهنده، مدل، کلیدها،
بودجه‌ها، سوئیچ قابلیت‌ها و پرسونا را عوض می‌کند — با اعتبارسنجی، تاریخچهٔ
تغییرات و ذخیرهٔ رمزنگاری‌شدهٔ کلیدها.

**داده‌ات مال خودت می‌ماند.** تاریخچهٔ گفتگو، حافظه و یادآورها در `bot.db` تو
هستند. چیزی بیرون نمی‌رود جز درخواست‌هایی که برای پاسخ به همان پیام لازم‌اند، و
`/deletemydata` دادهٔ یک نفر را در یک تراکنش پاک می‌کند.

## قابلیت‌ها

| حوزه | چه چیزی می‌گیری |
| --- | --- |
| گفتگو | تاریخچهٔ پایدار هر چت در SQLite، خلاصهٔ غلتان، حافظهٔ بلندمدت با ابزارهای `search`/`save`/`forget` |
| مدل‌ها | Gemini (بومی) یا هر درگاه سازگار با OpenAI؛ انتخاب مدل برای هر کاربر، تغییر از `/admin` |
| بازیابی اطلاعات | جستجوی وب کنترل‌شده با گیت تازگی، بازکردن صفحه، آب‌وهوا از Open-Meteo (بدون کلید) |
| رسانهٔ ورودی | عکس، سند تصویری، استیکر، ویس، صدا، ویدیو، ویدیومسیج، سند، لینک یوتیوب |
| رسانهٔ خروجی | عکس واقع‌گرایانه با Pollinations (اختیاری)، تصویر برداری از SVG به‌صورت محلی، میم واقعی از ردیت (بدون کلید) |
| یادآور | یادآور یک‌باره با منطقهٔ زمانی هر کاربر، درک عبارت‌های طبیعی فارسی، ارسال با منشن در گروه |
| گروه‌ها | فقط گروه‌های مجاز، واژهٔ فراخوانی و منشن، پاسخ با آگاهی از گوینده، فاصلهٔ محتاطانهٔ استیکر |
| عملیات | پنل `/admin`، بررسی سلامت، مایگریشن نسخه‌دار، اسکریپت سرویس، سهمیهٔ هر کاربر |
| زبان‌ها | فارسی (پیش‌فرض) و انگلیسی، برای هر کاربر، با کاتالوگ کامل رابط |
| حریم خصوصی | `/deletemydata` (پیش‌نمایش سپس تأیید)، بدون آنالیتیکس شخص ثالث، کلیدها هرگز برنمی‌گردند |

## شروع سریع

به یک توکن ربات از [@BotFather](https://t.me/BotFather) و یک کلید مدل نیاز داری:
کلید [Google AI Studio](https://aistudio.google.com/apikey) یا هر کلید سازگار با
OpenAI.

```bash
git clone https://github.com/canoheil/Aura.git
cd Aura

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# edit .env: TELEGRAM_BOT_TOKEN and GEMINI_API_KEY (or the OPENAI_* trio)

python bot.py
```

آورا از long polling تلگرام استفاده می‌کند — نه وبهوک، نه پورت عمومی، نه
گواهی TLS. وقتی `Bot is running` در لاگ آمد، به ربات پیام بده.

دو کار ارزشمند در اولین اجرا:

- `FOUNDER_USER_ID` را روی Telegram ID خودت بگذار (`/whoami` نشانش می‌دهد) تا
  `/admin`، `/settings` و سهمیهٔ نامحدود مال تو باشد؛
- `bot.db` را از گیت دور نگه دار. همهٔ پیام‌ها در آن است و `repo_guard.py` جلوی
  کامیت‌شدنش را می‌گیرد.

`requirements-pinned.txt` نسخه‌های دقیقی را پین می‌کند که این نسخه با آن‌ها
آزموده شده؛ برای محیط بازتولیدپذیر از آن به‌جای `requirements.txt` استفاده کن.

## دستورها

| دستور | کار |
| --- | --- |
| `/start` | خوش‌آمد، مدل فعلی، فهرست دستورها |
| `/new` | شروع گفتگوی تازه (حافظه و یادآورها می‌مانند) |
| `/model`، `/models` | نمایش یا تغییر مدل؛ فهرست مدل‌های ارائه‌دهنده |
| `/memory`، `/remember <متن>`، `/forget <متن>` | دیدن، افزودن و حذف حافظهٔ بلندمدت |
| `/stats` | آمار گفتگو و حافظه |
| `/image <پرامپت>` | ساخت تصویر، یا ویرایش عکسی که به آن ریپلای کرده‌ای |
| `/remind <زمان> <کار>` | ثبت یادآور یک‌باره |
| `/reminders`، `/cancelreminder <id>`، `/timezone` | مدیریت یادآورها و منطقهٔ زمانی |
| `/language` | جابه‌جایی بین فارسی و انگلیسی |
| `/usage` | شمارندهٔ امروز، سهمیه و زمان بازنشانی |
| `/deletemydata` | پیش‌نمایش و سپس پاک‌کردن همهٔ داده‌های شخصی |
| `/whoami` | Telegram ID و وضعیت سازنده |
| `/settings` | فقط مالک: مدیریت فهرست گروه‌های مجاز |
| `/admin` | پنل سازنده/ادمین: تنظیمات، تست ارائه‌دهنده، تاریخچهٔ تغییرات |

دستورها تنها راه نیستند؛ جملهٔ معمولی هم کار می‌کند: «۱۰ دقیقه دیگه یادم بنداز آب
بخورم»، «هوای تهران چطوره؟»، «یه میم بده» و «عکس بساز از یک گربه فضانورد» به‌عنوان
درخواست فهمیده می‌شوند، نه به‌عنوان متن.

## چطور کار می‌کند

یک پیام می‌رسد، `bot.py` تشخیص می‌دهد چه نوع نوبتی است، و بقیه چیزها ابزارهایی
هستند که مدل از طریق یک حلقهٔ عامل محدود صدا می‌زند:

```
Telegram ─▶ handler ─▶ prompt layers ─▶ agent loop ─▶ tool registry ─▶ model
                             │                  │
                    identity, boundaries,   web search · weather · memes ·
                    persona, freshness      images · SVG · files · memory ·
                                            reminders · stickers
```

حلقه بودجهٔ ثابت دارد (`AGENT_MAX_ROUNDS`، `AGENT_MAX_TOOL_CALLS`)، فراخوانی‌های
تکراری یک نوبت را ادغام می‌کند، و به‌محض کافی‌بودن شواهد می‌ایستد. هیچ‌چیز از
ارائه‌دهنده در هندلرها سخت‌کد نشده، پس یک نوبت روی Gemini و روی یک مدل محلی Ollama
یکسان کار می‌کند.

| فایل | مسئولیت |
| --- | --- |
| `bot.py` | هندلرهای تلگرام، مونتاژ پرامپت، تحویل |
| `tool_system.py` | رجیستری ابزار و حلقهٔ عامل محدود |
| `providers.py` | کلاینت Gemini و سازگار با OpenAI پشت یک رابط |
| `settings_store.py`، `admin_panel.py` | تنظیمات زمان اجرا، پنل `/admin`، تاریخچه |
| `aura_identity.py`، `aura_personality_boundary.py`، `persona.py` | کیستی آورا و جایی که سبک مجاز است تغییر کند |
| `freshness_policy.py`، `answer_quality.py` | چه‌وقت جستجو اجباری است و پاسخ معتبر چه شکلی است |
| `reminders.py`، `memory_bridge.py`، `data_deletion.py` | وضعیت پایدار و چرخهٔ عمرش |
| `telegram_formatting.py`، `i18n.py` | HTML کپی‌سالم و کاتالوگ فارسی/انگلیسی |
| `sticker_manager.py`، `sticker_vision.py`، `svg_image.py`، `pollinations_image.py`، `meme_api.py`، `weather_api.py` | قابلیت‌های اختیاری |

جزئیات بیشتر — از جمله دلیل لایه‌بندی پرامپت — در
[docs/architecture.md](docs/architecture.md) است.

## پیش‌نیازها

- پایتون ۳٫۱۱ یا بالاتر
- توکن ربات تلگرام
- یک کلید مدل: Gemini (`GEMINI_API_KEY`) یا هر درگاه سازگار با OpenAI
  (`OPENAI_API_KEY`، `OPENAI_BASE_URL`، `OPENAI_MODEL`)
- اختیاری: `YOU_API_KEY` برای جستجوی وب، `POLLINATIONS_API_KEY` برای تولید عکس
- بدون سرور دیتابیس، بدون داکر، بدون reverse proxy

## تست‌ها

مجموعه تست هرمتیک است — کلاینت‌های تقلبی تلگرام و مدل، بدون کلید API، بدون شبکه —
و حدود ده ثانیه طول می‌کشد:

```bash
pip install -r requirements-dev.txt
python -m pytest
ruff check .
```

CI هر دو کار را روی هر push و pull request اجرا می‌کند
([`.github/workflows/tests.yml`](.github/workflows/tests.yml)). ساختار پروژه،
هوک‌های pre-commit و قواعد یک pull request در [CONTRIBUTING.md](CONTRIBUTING.md)
آمده است.

## وضعیت پروژه

آورا به‌صورت باز توسعه می‌یابد و در محیط واقعی اجرا می‌شود. تنها شاخهٔ
پشتیبانی‌شده `main` است و هر تغییر از طریق pull request وارد می‌شود که باید تست‌ها
و linter را پاس کند. رابط‌ها ممکن است هنوز تغییر کنند؛ اسکیمای دیتابیس نسخه‌دار
است و فقط رو به جلو مایگریت می‌شود، هرگز بی‌صدا بازنویسی نمی‌شود.
